# Prometheus Monitoring Installers

Current baseline: **v6r4-RC3** — server-UAT release candidate.

This repository contains production-oriented Linux installers for seven monitoring components, active source/tests, and archived historical delivery material.

## Production installers

Use only the files under [`installers/`](installers/) on target servers:

- Alertmanager
- Blackbox Exporter
- Grafana
- Node Exporter
- Prometheus
- SNMP Exporter
- VictoriaMetrics single-node

Each production installer is a **single self-contained shell script**. No sibling `common/platform.sh` is required or loaded at runtime.

## Repository layout

- `installers/` — seven self-contained production/UAT installer scripts only.
- `src/v6r4-RC3/` — active source, shared build-time `common/platform.sh`, configs and tests.
- `tools/` — supporting tools such as node discovery.
- `docs/` — current RC3 baseline, UAT and lifecycle rules.
- `releases/v6r4-RC3/` — deterministic RC3 ZIP and SHA256 generated by GitHub Actions.
- `archive/` — historical snapshots; never treat archived files as the current baseline.

## RC3 lifecycle policy

RC3 is intended for real Linux server UAT. It is **not GA**. A GA tag should only be created after the seven installers pass install/status/probe/reload/reinstall/uninstall verification on representative Linux hosts.

See [`docs/RC3_BASELINE.md`](docs/RC3_BASELINE.md) and [`docs/RC3_SERVER_UAT.md`](docs/RC3_SERVER_UAT.md).
